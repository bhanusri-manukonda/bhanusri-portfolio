**Key Features**
- Book catalogue with 60+ seeded books and book-cover images.
- Book categories, search, and detailed book pages.
- Discounted pricing with original and final prices.
- Persistent wishlist with backend synchronization.
- Shopping cart, checkout, and order management.
- JWT-based authentication and protected routes.
- Admin dashboard for managing books, users, and orders.
- Book recommendations based on category and author.

**What I Practiced:** REST API integration, database models, authentication, React context, application state management, and full-stack development.
